# 中文待办事项

一个使用 HTML、CSS 和原生 JavaScript 构建的轻量级中文待办事项网页，无需安装依赖即可运行。

## 功能特点

- 添加新的待办事项；
- 将事项标记为已完成，或取消完成状态；
- 删除不再需要的事项；
- 实时显示待完成和已完成的事项数量；
- 使用浏览器 `localStorage` 自动保存数据，刷新页面后仍会保留；
- 响应式页面设计，可适配电脑和手机；
- 支持键盘操作，并为交互控件提供无障碍标签。

## 运行方法

### 方法一：直接打开

直接使用浏览器打开项目根目录中的 `index.html` 文件即可。

### 方法二：启动本地静态服务器

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

## 项目结构

```text
.
├── index.html   # 页面结构
├── style.css    # 页面样式与响应式布局
├── script.js    # 待办操作与本地存储逻辑
└── README.md    # 项目说明
```

## 数据说明

待办数据只会存储在当前浏览器的本地存储中，不会上传到服务器。清除该网站的浏览器数据后，已保存的待办事项也会被清除。
