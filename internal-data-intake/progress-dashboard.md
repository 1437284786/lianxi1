# Phase 2 P0 进度看板

> 当前产品进度只能从 `p0-master-checklist.csv` 的工作流状态计算，不填写主观百分比。当前基线日期：2026-06-08。所有一级、二级项目均为 `not_started`；未来产品仅保留状态栏，不计入本轮 P0 完成率。

## 1. 状态口径

- 分母：对应产品和类别的 P0 项目数。
- 完成数：仅统计 `approved` 和经责任部门确认的 `not_applicable`。
- 收件不等于完成：`received`、`under_review` 不计为完成。
- 展示格式：`完成数 / 总数`，并列出状态分布；不在无数据时虚构百分比。

## 4. 刷新方法

运行校验脚本确认 CSV 有效后，按 `product_id + data_category + status` 重新汇总本表。每次刷新记录日期；如果增加、合并或拆分 P0 项，必须同步更新分母和说明。
