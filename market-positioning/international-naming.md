# 国际命名方案

## 1. 总体原则

- 通用材料名优先使用 `Brown Fused Alumina (BFA)`；面向美国语境可接受 `Brown Fused Aluminum Oxide`。
- 内部“一级/二级”不是已确认的国际标准等级，不直接形成 `First Grade`/`Second Grade` 页面名。
- 用途型名称只有在我方规格和适配完成验证后才可使用。
- 处理型名称必须描述真实工艺；“原料铝矾土煅烧”不等于“成品 BFA 二次热处理”。
- 包覆材料不明时只使用 `Surface-treated`，不得猜测具体元素或涂层。

## 3. 页面命名模板

优先模板：

```text
Brown Fused Alumina for [verified application] — [verified grit system / defining property]
```

示例只用于结构说明，不表示我方当前可用：

- `Brown Fused Alumina for Bonded Abrasives — FEPA F Grit`；
- `Brown Fused Aluminum Oxide for Blasting — [Approved Size Range]`；
- `Brown Fused Alumina for Refractory Castables — [Approved Fraction]`。

若同一产品不能同时满足不同用途，应按经批准规格拆成 SKU/grade，不用一个页面覆盖所有行业。

## 4. 术语风险

- `Brown Corundum` 可作别名，但国际主名称优先 BFA。
- `Emery` 不应作为 BFA 的默认同义词；公开产品卡把 Turkish Emery 与 Brown Aluminum Oxide 分列（SRC-009）。
- 中文“金刚砂”不能直译为 `Diamond Sand`。
- `Calcined Alumina`、`White Fused Alumina`、`Zirconia Alumina` 等不是本项目产品的同义词。
- `virgin`、`recycled`、`reclaimed` 必须有原料与生产证据，尤其不得对二级产品自行推断。

## 5. 命名批准流程

技术定义 → 质检规格与方法 → 应用/客户验证 → 法规与文件核对 → 外贸语义检查 → 管理层批准 → 更新产品主数据。任一关键环节未完成，名称保持 `Technical Designation Pending`。
