# 待管理层决定事项

> 决策前应先取得下表“最低输入”。未满足时可记录方向偏好，但不得升级为外部产品承诺。

| ID | 决策问题 | 建议选项/框架 | 最低输入 | 建议时点 | 当前建议 |
|---|---|---|---|---|---|
| DR-01 | 是否优先推广一级还是二级 | 一级主力 / 二级主力 / 按应用双轨 | 分级定义、规格、成本、现有客户、交付 | P0 数据后 | 暂以一级为主力候选、二级为补充；非最终决定 |
| DR-02 | 以磨具还是喷砂为第一切入口 | 磨具优先 / 喷砂优先 / 双通道验证 | 可供粒度、关键质量指标、客户记录、小试 | P0 + 初步应用试验后 | 双通道验证，避免在证据不足时押注 |
| DR-03 | 是否将耐火材料列为主要市场 | 主要 / 补充 / 暂不进入 | 段砂能力、化学稳定、客户配方和交付 | P1 前 | 保留候选，不列主要市场 |
| DR-04 | 二级产品允许哪些应用、禁止哪些应用 | 按规格白名单 | 来源、杂质、粒度、污染和客户验证 | P0 | 未形成白名单前不泛化推荐 |
| DR-05 | 是否计划定制包装/私标 | 标准包装 / 有条件定制 / 私标 | 包装线、MOQ、成本、标签法规、追溯 | 商业资料阶段 | 先确认能力，不作当前承诺 |
| DR-06 | 是否建立英文品牌和牌号体系 | 公司品牌 + 功能牌号 / 仅描述性名称 | 商标检索、品牌策略、SKU 架构 | 最终命名前 | 先用描述性工作名称 |
| DR-07 | 一级/二级最终国际名称 | 按用途/规格命名 / 经定义的字母牌号 | 完整技术定义和语义审核 | P0 数据后 | 禁用 First/Second Grade 作为最终名 |
| DR-08 | 煅烧设备投资与预计上线时间 | 立项 / 试验 / 暂缓 | 客户问题、设备方案、成本、指标、试验 | 设备决策前 | 不公布日期；先完成技术立项 |
| DR-09 | 煅烧产品优先应用 | 树脂磨具 / 陶瓷磨具 / 涂附磨具 / 其他 | 客户需求、原料/工艺和 A/B 方案 | 中试前 | 以最有客户协同条件的单一场景开始 |
| DR-10 | 表面处理产品实际工艺路线 | 陶瓷/硅烷/氧化物/其他 | 配方、是否含 Ir、法规、目标胶系 | 研发立项前 | 先完成“镀铱/镀衣”事实核验 |
| DR-11 | 是否使用任何含 Ir 命名 | 仅有元素与工艺证据时使用 / 禁用 | 成分检测、配方、法规和技术意义 | 命名前 | 当前禁用 `Iridium-coated Corundum` |
| DR-12 | 未来产品如何对外披露 | 不披露 / 研发路线 / 经批准预发布 | 生命周期 gate、预计时间、样品与风险 | 商业批准后 | 当前不作为可供产品披露 |
| DR-13 | 是否接受联合开发模式 | 接受 / 限定客户 / 不接受 | 技术资源、保密/IP、样品和试验流程 | 特殊品开发前 | 对煅烧/处理品建议限定客户联合开发 |
| DR-14 | 产品规格是否按应用拆分 SKU | 单一通用品 / 磨具、喷砂、耐火拆分 | 各用途限值、生产切换和追溯 | 数据成型后 | 倾向按经验证用途拆分，不强求一品多用 |
| DR-15 | Phase 2 的责任人与完成期限 | 按字段指定技术/质检/生产/外贸 | P0 清单、受控文件流程 | 立即 | 先指定责任人；本文件不虚构期限 |

## 决策记录要求

形成关键决定后，应在 `DECISIONS.md` 记录日期、决定、理由、证据、批准人和复审条件；若改变项目阶段或依赖，同时更新 `PROJECT_STATUS.md` 与 `ROADMAP.md`。本次没有替管理层作出上述最终决定。
