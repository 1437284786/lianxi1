# 产品组合策略

## 1. 当前阶段：一级 + 二级棕刚玉

| 角色 | 初步安排 | 目标客户 | 所需资料 | 推广前提 | 主要风险 |
|---|---|---|---|---|---|
| 主力产品 | 一级棕刚玉，先定位为标准工业级验证候选 | 磨具、涂附磨具、喷砂、耐火客户中的合格线索 | 分级定义、规格、粒度、COA/TDS/SDS、应用记录 | 最终名称、可供 SKU 和应用边界批准 | 未验证即宣称 premium 或多用途 |
| 引流产品 | 二级棕刚玉，面向规格匹配和成本敏感询盘 | 经销商、进口商、一般工业应用客户 | 来源、杂质/粒度、禁用场景、批次与包装 | 不用 `Second Grade` 作最终页面名；明确质量边界 | 被理解为废料/再生料或低质品；污染/性能风险 |
| 利润型产品 | 当前不能确定 | 待成本与成交数据确认 | 成本、价格、订单、毛利（本任务不制定价格） | 管理层批准 | 凭主观把一级定义为高利润 |
| 技术形象产品 | 当前不能确定；可由“透明规格与证据能力”承担而非虚构特殊品 | 技术采购和质量部门 | 文件包、测试方法、追溯 | 证据齐备 | 将未来产品包装成当前能力 |

### 当前组合销售逻辑

- 不用“一级一定比二级适合所有场景”的单轴逻辑；用“客户规格—应用—证据—供货”匹配。
- 询盘先收集用途、粒度体系、目标规格、月/年需求（由客户提供）、包装与验证要求，再选择候选产品。
- 二级若无法通过客户关键限值，应停止推荐，不用低价推动不合格应用。
- 当前阶段不把煅烧或表面处理品列入报价、交期、现货、样品承诺。

## 2. 设备升级阶段：引入煅烧棕刚玉

| 角色 | 初步安排 |
|---|---|
| 主力产品 | 已批准的一级常规品继续承担稳定销量基础 |
| 引流产品 | 二级和常规一级中的标准 SKU |
| 利润型产品 | 煅烧棕刚玉（仅为待验证角色） |
| 技术形象产品 | 具有处理前后数据的煅烧 BFA |
| 目标客户 | 树脂/陶瓷固结磨具和涂附磨具制造商、专业经销商 |
| 所需资料 | 设备验收、温度/时间/气氛、原料、处理前后成分/物性、磨具 A/B、产能、成本、TDS/SDS |
| 推广前提 | 样品稳定、客户试验、产品命名与商业批准、可重复量产 |
| 主要风险 | 把原料煅烧与成品二次处理混淆；无量化结果；升级成本不能被客户价值覆盖；批次色差/性能波动 |

建议采用 stage-gate：实验室样 → 中试 → 三批稳定性 → 客户 A/B → 文件与法规 → 商业批准。预计上线时间不得在上述门槛前承诺。

## 3. 技术升级阶段：表面处理棕刚玉

| 角色 | 初步安排 |
|---|---|
| 主力产品 | 经验证的常规 + 煅烧产品组合 |
| 引流产品 | 规格化常规 BFA |
| 利润型产品 | 表面处理 BFA（仅为假设） |
| 技术形象产品 | 与特定树脂/胶黏剂共同开发并有对照数据的处理品 |
| 目标客户 | 树脂砂轮、切割片、角磨片、砂带/涂附磨具制造商 |
| 所需资料 | 正式名称、是否含 Ir、包覆材料/量/工艺、均匀性、储存、SDS/法规、相容性、植砂/吸胶、成品 A/B |
| 推广前提 | 材料与知识产权边界明确；技术/质量/HSE/商业批准；客户试用通过 |
| 主要风险 | “镀铱”误译和元素/法规风险；配方泄密；处理层衰减；只对特定胶系有效却泛化；生产一致性不足 |

## 4. 组合治理规则

1. 每类产品独立 `product_id`、规格、文件、样品标签和生命周期状态。
2. 当前产品和未来产品不得共用“available/current supply”表述。
3. 产品角色不是永久标签，应由订单、应用结果、成本和客户反馈在后续阶段复核。
4. 任何新处理品不得仅因竞品存在而立项；必须先定义客户问题和量化成功指标。
5. 品牌/牌号体系在英文品牌决策后统一，不提前创建看似已注册的虚假商标。
